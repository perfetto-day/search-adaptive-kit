# Search Adaptive Kit v0.8

Экспериментальное адаптивное оформление [Search Browser](https://github.com/driceroland/Search) для macOS. Это **патч нативного SwiftUI-интерфейса**, а не расширение Chrome. Оригинальный Search не заменяется: создаётся `~/Applications/Search Adaptive.app`.

## Что нового

- **Адаптивный поиск:** для светлой страницы поле ввода светлее затемнённой подложки, для тёмной сохраняет тёмный оттенок. Верхние вкладки и кнопки затемняются целиком, а не только их фон (нативные macOS traffic lights — исключение).
- **Seamless-скругления:** два верхних угла веб-страницы с радиусом 10 pt. Дополнительные линии, рамки, отступ сверху и тени убраны: на однородном фоне скругление практически незаметно, на неоднородном проявляется естественно.
- **Параметры в браузере:** `search://settings/appearance` → `Search Adaptive` и `Mod updates`: используются штатные карточки, строки, разделители, чёрно-белые переключатели и кнопки Search. Все настройки остались доступны.
- **Обновление мода в браузере:** кнопка `Check GitHub branches and tags`, выбор ветки / тега и точного SHA коммита, затем отдельно `Download & Build` и `Install & Restart`.
- **Безопасный откат:** сборка выполняется во временном управляемом клоне, до установки не затрагивает текущую программу. При неудачной сборке прежняя `.app` остаётся на месте. Установка выполняется только после второго подтверждения и завершения браузера.

### Важно про обновление из GitHub

Браузер получает список ревизий **только** из публичного `perfetto-day/search-adaptive-kit`. При нажатии «Download & Build» скачанный код и скрипты **исполняются на вашем Mac**. Поэтому **выбирайте только доверенные коммиты**. Проверка доступности и скачивание/сборка никогда не запускаются без явного нажатия кнопки. Полноценная криптографическая верификация подписи коммита не реализована; сравнивается выбранный SHA с полученным Git ref, а переключившийся ref отклоняется.

Новые версии оригинального Search проверяются по умолчанию, но **не заменяют** Search Adaptive стандартной сборкой. Вы увидите уведомление и сможете пересобрать модифицированную версию.

## Apple Passwords и Passkeys в собственной сборке

**Ограничение macOS:** официальный Search подписан разработчиком Office Commun, а сборка `Search Adaptive.app` создаётся на твоём Mac с ad-hoc подписью. Apple Passwords использует защищённый системный `PasswordManagerBrowserExtensionHelper`, который macOS разрешает запускать только известным подписанным браузерам или приложениям с соответствующим разрешением. Поэтому скопировать исходники Search, поменять bundle ID или активировать галочку недостаточно. Система может вывести `Apple's Passwords helper wouldn't run for this copy of Search`.

Это **отдельно от passkeys** — для входа с ключами на произвольных сайтах Apple требует entitlement `com.apple.developer.web-browser.public-key-credential`, который предоставляется браузерным разработчикам через процедуру Apple. Мы не отключаем проверку подписи и не имитируем официальную сборку.

Если нужен собственный браузер с полноценной интеграцией Apple Passwords: потребуется подписывать его собственным Apple Developer ID, заявить идентификатор браузера в [apple/password-manager-resources](https://github.com/apple/password-manager-resources#how-apple-uses-web-browser-extension-distribution-information), получить одобрение Apple и дождаться обновления macOS со списком разрешённых браузеров. Для Passkeys потребуется отдельный запрос entitlement. **Это не автоматически заработает после одной правки проекта**.

Проверить сведения о подписи установленной программы:

```bash
codesign -dv --verbose=4 "$HOME/Applications/Search Adaptive.app" 2>&1 | grep -E 'Identifier=|TeamIdentifier=|Signature='
```

До получения разрешений можно пользоваться встроенным в Search хранилищем паролей/Keychain (не путать с прямым чтением Apple Passwords) или отдельно использовать официальную сборку браузера для нужных сайтов.

## Установка v0.8 на Mac

Полный Xcode, Git и Python 3 обязательны. Выполни:

```bash
cd ~/Downloads/search-adaptive-kit
git fetch origin
git switch feat/v0.8-native-settings-seamless-corners
git pull --ff-only
./update-and-build.sh
```

Затем:

```bash
./toggle-mode.command on
open "$HOME/Applications/Search Adaptive.app"
```

После запуска перейди по адресу `search://settings/appearance`, прокрути до группы **Search Adaptive**. Настройки хранятся в тех же `UserDefaults`, что и переключатели CLI. Если включаешь адаптивность после её отключения, обнови вкладки (новым страницам WebKit внедряет цветовой детектор при загрузке). Для правильной перестройки углов иногда требуется перезапуск.

## CLI-переключатели

```bash
./toggle-mode.command on            # адаптивные цвета
./toggle-mode.command off
./toggle-mode.command search-on     # адаптивный поиск
./toggle-mode.command search-off
./toggle-mode.command round-on      # верхние скругления
./toggle-mode.command round-off
./toggle-mode.command debug-on      # источник и цвет панели
./toggle-mode.command debug-off
./toggle-mode.command updates-on    # уведомления об официальном Search (по умолчанию)
./toggle-mode.command updates-off
./toggle-mode.command status
```

## Обновление мода из браузера

1. Открой `search://settings/appearance`.
2. Нажми **Check GitHub branches and tags** — без исполнения удалённого кода.
3. Выбери `main`, ветку PR или тег. Точный сокращённый SHA отображается рядом.
4. Нажми **Download & Build**, прочти подтверждение, разреши локальную сборку. Лог: `~/Library/Application Support/SearchAdaptive/mod-update.log`.
5. Только после успешного завершения появится **Install & Restart**. Нажми — приложение выйдет, помощник заменит его, запустит новую версию. При ошибке предыдущая сборка сохраняется.

Рабочая папка модификации: `~/Library/Application Support/SearchAdaptive/`. Удалённый код **не** может автоматически нажать «Install & Restart»: это действие выполняется только пользователем.

## Из терминала

Для обновления из ветки текущего клона (когда браузер закрыт):

```bash
git pull --ff-only
./update-and-build.sh
```

Исходный Search берётся из `driceroland/Search`, а наш мод собирается из текущего клона. Патчер изменяет восемь штатных файлов Swift (`Tab`, `App`, `Side`, `TabBar`, `Omnibox`, `Stage`, `Settings`, `Updater`) и копирует два модуля (`AdaptiveChrome.swift`, `AdaptiveSettings.swift`). При изменении ожидаемых конструкций в оригинальном Search патчер безопасно остановится.

## Диагностика

- Если прежняя программа запускается вместо новой, явно открой `~/Applications/Search Adaptive.app`.
- Если сборка сообщает `SwiftUIMacros.StateMacro not found`, проверь установку полного Xcode: `DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer ./update-and-build.sh`.
- Если не видишь скруглений, убедись, что включён режим горизонтальных вкладок и опция Round page top corners. Для режима «страница-карточка» Search уже скругляет четыре угла самостоятельно.
- Если поле поиска на тёмной странице светлое, проверь, что действительно установлена v0.8 и адаптивный режим включён. При необходимости выполни `./toggle-mode.command debug-on`.
- После обновления оригинального Search от ноября 2026 изменились `Side.swift` и `TabBar.swift`. Начиная с v0.8 патчер поддерживает и старый, и новый вариант. Если структура снова поменяется, ошибка `upstream changed; stopped safely` означает безопасную остановку без замены приложения.

Этот проект независим от Office Commun; оригинальный браузер [Search](https://github.com/driceroland/Search) распространяется под MIT.


### Поправки v0.8: Peek и верхние углы страницы

- При открытии Peek поверх страницы горизонтальная панель вкладок затемняется **на те же 22%**, что и фон страницы (включая иконки и активную вкладку). Для вертикального сайдбара при включённом адаптивном оформлении действует то же затемнение.
- Скругления верхних углов теперь применяются дважды: к нативному контейнеру WebView и ко всей поверхности страницы в SwiftUI. Маска переустанавливается при изменении размеров окна/переносе WebView. Это нужно для страниц с градиентными или изображёнными фонами. **Никаких обводок, дополнительных отступов или теней не добавляется**.
- На однотонном фоне, точно совпадающем с цветом панели вкладок, скругления намеренно почти незаметны — seamless-эффект сохраняется.
- Если стиль не меняется после сборки, убедись, что включены горизонтальные вкладки и `Round page top corners`, перезапусти Search Adaptive и проверь на странице с контрастным верхним фоном.

## Исправления v0.8: совместимость с Search и GitHub

- Поддерживаются новые структуры `Side.swift` (раздельный фон и подсветка перетаскивания, контраст текста) и `TabBar.swift` (оттенки через `greys`). Старые конструкции тоже распознаются.
- Проверка GitHub теперь показывает реальный HTTP-код, сообщение сервера и ограничение запросов с примерным временем восстановления, если оно известно.
- Если недоступен список тегов, но ветки загрузились, меню показывает ветки с предупреждением вместо полного сбоя.
- Настройки и скругления из v0.7 не менялись. Для установки используйте ветку PR; после слияния переключайтесь обратно на `main`.
