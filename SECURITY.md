# Security Policy

Search Adaptive Kit patches and rebuilds a browser, which handles browsing data, sessions and potentially sensitive credentials.

- This project has **not** undergone a security audit.
- Build from code you have reviewed. Do not run unknown third-party installer scripts.
- The modified app is **not signed or released** by the official Search authors.
- Use the dedicated build checkout; keep browser profile backups.
- Never publish your local profile, cookies, tokens, passwords, internal web pages or diagnostic logs containing sensitive data.

For an issue that could expose user data, **do not post the reproduction publicly**. Instead, contact the repository maintainer privately through GitHub before disclosing technical details.

The original browser and its updates are maintained at https://github.com/driceroland/Search.
